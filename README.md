# RetailFlow — Production-Style Lakehouse Platform

A personal data engineering project built with Databricks,
PySpark, Delta Lake, and SQL.

## Project Goal

Build a reliable, production-style lakehouse pipeline that
transforms raw e-commerce data into analytics-ready datasets.

## Architecture

Bronze (Raw Data) -> Silver (Cleaned Data) -> Gold (Analytics)

## Planned Features

- Batch ingestion with PySpark
- Delta Lake tables and ACID transactions
- Data quality checks and invalid-record quarantine
- Deduplication and incremental processing
- Delta MERGE operations
- Star-schema data modelling
- Business analytics using SQL
- Pipeline orchestration and monitoring
- Automated data validation tests
- Performance tuning and documentation

## Dataset

Brazilian E-Commerce Public Dataset by Olist.

Dataset source:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Review the dataset licence before redistributing the data
or using the project for commercial purposes.
